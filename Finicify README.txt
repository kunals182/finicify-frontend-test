# 🧭 Finicify Frontend Developer Test

This repository contains the submission for the **Finicify Frontend Developer Test**, built using **React + Vite + TypeScript + Tailwind CSS + Recharts + Framer Motion**.

---

## 🚀 Overview

This project includes **two tasks**:

### ✅ **Task 1 – Company Internal Comparison Dashboard**
A responsive and interactive dashboard displaying:
- **Comparison toggle**: “Compare with Sector” & “Compare Within Company”
- **Metric cards** (Revenue Growth, Profit Margin, Return on Assets)
- **Dynamic charts**:
  - Risk Metrics Heatmap
  - Sector Risk Analysis (Pie Chart)
  - Internal Comparison Chart (Bar Chart)
- Smooth animations with **Framer Motion**
- Clean & modern UI with **TailwindCSS**

---

### ✅ **Task 2 – Additional Feature / Enhancement**
Added features include:
- **Dark Mode Toggle** 🌙
- **Download Chart as Image (PNG)** 📊
- Improved responsive layout
- Smooth transitions & interactive visuals

## 💻 **Setup Instructions**

1. Clone the repository:
   ```bash
   git clone https://github.com/kunals182/finicify-frontend-test.git
   ```

2. Navigate to the project folder:
   ```bash
   cd finicify-frontend-test
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Run the project locally:
   ```bash
   npm run dev
   ```

5. Open in browser:
   ```
   http://localhost:5173/
   ```
